# ביקור הגברת הזקנה · ספרות י״ב · מצגת רשת

מצגת על המחזה של פרידריך דירנמט (תרגום טובה קשת, אור־עם 1983) להכנה לבגרות. בסיום יש שאלת בגרות אמיתית (8281, חורף תשפ״ה, שאלה 8) ותשובה לדוגמה מלאה עם סימונים.

- אתר חי: https://kita-gveret-zkena.vercel.app
- `index.html`: המצגת (21 שקופיות, RTL, ניווט במקלדת, בלחיצה ובהחלקה, מסך מלא)
- `teacher.html`: אזור המורים (עם קוד). `teacher.html#presenter`: תצוגת מציג
- `handout.html`: דף עבודה להדפסה · `cards.html`: כרטיסי לוח הבחירה
- תוכנית הלימודים: https://meyda.education.gov.il/files/Mazkirut_Pedagogit/sifrut/chativa_elyona_tochnit.pdf#page=7

תמונת דירנמט: Elke Wetzig, CC BY-SA 3.0, Wikimedia Commons. ציטוטים קצרים בלבד, עם הפניה למערכה.
